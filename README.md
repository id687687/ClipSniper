# 段子剪刀手 (ClipSniper) - Android 群聊文案极简采集器

专为微信、QQ 等群聊设计的零打扰文案采集工具。

---

## 🌟 核心特性

1. **自动剥离昵称与时间戳**：
   - 彻底解决微信/QQ 合并复制、长按复制时带有多余昵称、聊天日期的困扰。
   - 智能识别并清洗，纯正文一键收录。
2. **最新 5 条剪贴板记忆池**：
   - 自动维护最近复制的 5 条记录队列。
   - 在群里连续复制，点击悬浮球一次性批量审查并入库。
3. **轻量侧边悬浮小胶囊**：
   - 屏幕侧边常驻，可任意拖拽。
   - 点击瞬间弹出底部抽屉，勾选一键收录，全程不跳出微信聊天。
4. **离线便签与导出**：
   - 本地纯净存储，支持一键全部复制、导出为 Markdown 或分享到微信/手机便签。

---

## 🚀 两种打包运行方式

### 方式 1：使用 Android Studio 直接打开编译
1. 打开 **Android Studio** -> `Open` -> 选择 `Documents/ClipSniper` 目录。
2. 手机开启 USB 调试，点击顶部绿色的 **Run (运行)** 即可安装到手机。

### 方式 2：免安装本地环境，GitHub Actions 云端 2 分钟免费打包
1. 将本项目推送到你的 GitHub 仓库：
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/ClipSniper.git
   git push -u origin main
   ```
2. 进入 GitHub 仓库的 **Actions** 标签页，系统会自动编译生成 `ClipSniper-Debug-APK`。
3. 点击直接下载 APK 到手机安装即可！

---

## 📱 使用指南

1. 安装并首次打开 App，打开「**悬浮剪刀手服务**」开关（系统会提示开启“悬浮窗”权限）。
2. 返回微信群，看到好玩的文案直接**长按复制**。
3. 点击屏幕边缘的小剪刀悬浮球 `✂️`。
4. 弹出的待收录面板中，系统已为你剔除了昵称与时间，点击「**📥 一键收录到笔记**」即可！
